Personal Project · Python / JavaScript / Gemini API

Recipe Generator

Generates recipes from ingredients via two input modes: type them manually, or upload a photo and let Gemini analyze what's in it.

Complete
What it does

Users can either type a list of ingredients or upload an image of their fridge/pantry. Gemini analyzes the image for ingredients automatically, then the app generates a matching recipe with instructions.

How it works

Python/Flask backend connects to the Gemini API for both image analysis and recipe generation. Frontend built with HTML, CSS, and JavaScript. Recipes stored in a local JSON file for quick reference.

What I learned

Chaining multimodal AI calls — image analysis feeding directly into a generation prompt — required careful prompt engineering to get reliable, structured recipe output. Also learned to design intuitive dual-input UX.

Personal Project · Python / Pygame

Pac-Man

A Python Pac-Man clone with classic gameplay, dynamic ghost AI, a vulnerability mechanic, and a SHIP WERCK maze generation algorithm.

Beta / Playable
What it does

Full Pac-Man game where you eat white pellets to score and yellow pellets to trigger ghost vulnerability. The user picks how many ghosts to spawn. Lose all three lives and it's game over.

How it works

Built in Python using Pygame. Implements SHIP WERCK maze generation, collision detection, ghost pathfinding AI, and a vulnerability timer. Arrow keys or WASD control Pac-Man.

What I learned

Game loops, sprite collision systems, and ghost AI pathfinding all require precise timing coordination. The vulnerability mechanic taught me how to layer transient state on top of a base AI behavior without breaking the game loop.
