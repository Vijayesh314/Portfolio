Research · R / Random Forest / Kaggle Dataset

Stellar Classification with R

A machine learning model that classifies stars into one of six types — main sequence, dwarfs, giants, and more — based on physical characteristics, achieving ~98% accuracy.

~98% Accuracy
What it does

Trained a Random Forest classifier in R on 240 stars using features like temperature, luminosity, radius, absolute magnitude, spectral class, and color. The model reproduces the structure of the Hertzsprung–Russell diagram from first principles.

How it works

Cleaned and renamed features from a Kaggle dataset, performed exploratory data analysis with univariate, bivariate, and multivariate visualizations, then tuned the model's mtry parameter. Evaluated using precision, recall, F1, and accuracy — all ~98%.

What I learned

The model independently confirmed a core astrophysics relationship: stellar type is strongly correlated with position on the HR diagram. This taught me how ML can validate physical theory, not just predict labels.

Research · Python / Gaia DR3 / Anomaly Detection

Gaia Data for Stellar Outliers

Uses ESA Gaia mission astrometric data to detect stellar outliers — stars that deviate significantly from expected photometric, kinematic, or spectral behavior.

In Progress
What it does

Queries and processes Gaia DR3 catalog data to identify anomalous stars that sit off the main sequence in unexpected ways. Scripts in data/, outputs/, and src/ handle ingestion, cleaning, analysis, and visualization of the results.

How it works

Written entirely in Python. Uses the Gaia archive data pipeline with custom scripts for outlier detection, likely using statistical distance metrics or isolation-based methods to flag stars that don't fit expected population distributions.

What I learned

Working with real astronomical survey data requires significant cleaning and careful handling of measurement uncertainties. Also deepened understanding of Gaia's astrometric data model and what makes a star a genuine physical outlier versus a measurement artifact.
