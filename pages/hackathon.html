Speech-to-Sign Aid (STS)

A real-time accessibility tool that converts live speech into visual sign-based representations for Deaf and hard-of-hearing users.

MVP Complete
What it does

Converts spoken audio captured via the Web Speech API into normalized text, then maps keywords and phrases to sign animations and visual symbols — with automatic fingerspelling fallback for unsupported words.

How it works

Built on a Python/Flask backend with a rule-based sign mapping engine augmented by Google Gemini API for phrase and intent matching. The frontend displays matched signs in sync with live speech using HTML, CSS, and JavaScript.

What I learned

Designing for accessibility requires prioritizing speed and clarity over completeness. Learned how to architect a rule-based NLP pipeline alongside an LLM, and how to handle graceful fallback when vocabulary coverage runs short.

Emotional AI V2

Real-time voice emotion analysis that provides live feedback to help understand emotional states during conversations — with Firebase authentication and a live emotion timeline.

CAC Submission
What it does

Records audio in 30-second chunks, sends each to Gemini 2.0 Flash for emotion detection, then updates a live dashboard showing the detected emotion, an emotional timeline, and voice quality metrics (pitch, pace, energy, clarity).

How it works

Python/Flask backend processes 16kHz WAV audio from the browser's MediaRecorder API. Firebase handles authentication. The frontend visualizes results in real time using a custom emotion timeline component. Submitted as a CAC competition entry.

What I learned

Working with audio in the browser at low latency is non-trivial — MediaRecorder chunking, WAV formatting, and API response timing all had to be coordinated carefully. Also learned how to design an emotional feedback loop that feels helpful rather than intrusive.
